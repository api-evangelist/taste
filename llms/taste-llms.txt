# Taste Labs

> Taste Labs is a San Francisco research lab and infrastructure company building "the taste layer for AI" — decoding subjective design domains to end AI slop. Its Taste Engine API extracts brand/design guidelines from a reference and enhances website and slide-deck prompts so AI generation stays on-brand.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface (apis.yml + the live Taste Engine API OpenAPI). Source: https://api.tastelabs.com/openapi.json

## APIs

- [Taste Engine API](https://api.tastelabs.com/): extract design guidelines and generate/enhance creative briefs (prompt enhancement for websites and slide decks). Requires an Authorization: Bearer token.

## Operations

- POST /enhance/ — Enhance a website design prompt using brand guidelines (operationId enhance_prompt_enhance__post)
- POST /enhance/slides — Enhance a slides prompt using brand guidelines from a prior deck (operationId enhance_slides_prompt_enhance_slides_post)
- GET /health — Liveness check
- GET /health/full — Full health check
